# ПРОАБАКУС — демо лендинга

Интерактивное демо лендинга частной школы «ПРОАБАКУС» (1–5 классы и дополнительные занятия).
В объёме демо: шапка, hero и интерактивное расписание на повторяющуюся неделю.

> Это демонстрация. Расписание, занятия и имена преподавателей вымышленные.
> Форма записи ничего не отправляет и не сохраняет.

## Стек

HTML5, CSS3, vanilla JavaScript (ES-модули). Без фреймворков, сборщика и зависимостей.

## Запуск

ES-модули не работают при открытии файла напрямую (`file://`), нужен локальный HTTP-сервер.
Из корня проекта:

```bash
python -m http.server 5173
```

или

```bash
npx serve .
```

Затем откройте http://localhost:5173.

## Структура

```
index.html                      статическая разметка
css/styles.css                  стили
js/config.js                    настройки (ссылка на мессенджер, начальные фильтры)
js/data.js                      преподаватели, дни, группы, занятия
js/main.js                      расписание, фильтры, диалоги, демо-форма
public/images/school-pattern.jpg фон hero
public/images/logo-owl.png      сова из логотипа (вырезана из логотипа старого сайта школы abakus-kdr.ru)
```

## Настройка

- **Мессенджер.** В `js/config.js` задайте `messengerUrl` (например, ссылку на чат школы).
  Пока значение пустое, любой элемент с `data-action="messenger"` показывает сообщение «Связь со школой будет подключена в полной версии».
  Сейчас такой кнопки на странице нет: «Написать нам» убрана из шапки, логика и диалог сохранены.
- **Расписание.** Все занятия — в `js/data.js`. Количество занятий по дням считается из данных
  с учётом выбранных фильтров. Группа задаётся массивом `gradeIds` (`0` — подготовка к школе).

## Что реализовано

- Тип занятий и группа собраны в раскрывающийся список «Фильтры»: он открывается поверх контента
  (страница не сдвигается) и закрывается по «Готово», Escape или нажатию на свободное место —
  такое нажатие не срабатывает на элементах под ним, а прокрутка и протягивание список не закрывают.
- Фильтры по дню (Пн–Сб), типу занятий и группе работают совместно; класс фильтруется по `gradeIds`
  (например, 2 класс видит занятия для 1–2, 1–3 и 1–5 классов).
- Счётчики занятий по дням с правильным склонением, пустое состояние и «Сбросить фильтры».
- Запись в модальном окне: из карточки подставляются занятие, день, время и преподаватель,
  из hero и шапки — общая запись. Проверка обязательных полей, без отправки данных.
- Доступность: семантическая разметка, видимый фокус, клавиатура, `prefers-reduced-motion`,
  диалог на `<dialog>` (фокус внутри, Escape, возврат фокуса, блокировка прокрутки).
- Адаптивность: строки расписания на десктопе, карточки на мобильных.
